# Documentación técnica

Este directorio contendrá las decisiones de arquitectura, instrucciones de desarrollo y documentación de integración.

Los documentos originales se conservan en la raíz:

- `FIRELY_CONTEXTO_CODEX.md`: contexto integral y decisiones del equipo.
- `firely-descripcion.md`: descripción científica y funcional.
- `firely-plan.md`: plan de ejecución y prioridades.

La estructura inicial del repositorio es:

```text
apps/mobile/          Aplicación móvil con Capacitor
packages/contracts/   Contratos compartidos con la API
infra/docker/         Entorno de desarrollo en contenedores
docs/                 Documentación técnica
mobile-smoke/         Prueba Android ya compilada
```

La estructura deja espacio para incorporar los componentes del equipo cuando se acuerde su ubicación. No implica que el backend, el pipeline o la aplicación web ya estén implementados.
